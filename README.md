# ChatPlugin for Astralis [RP]
## [En cours de création ⌛]

__Liste de commandes__ : 
- **/me** : action RolePlay
- **/roll** : roulette de 0 à 100
- **/offchat** : Désactive le chat HRP (Global)

__Liste de système__ : 
- **Chat [HRP]** : Chat HRP d'une distance de *400* blocs (modifiable via config.yml)
- **Annonce [Pôle]** : Annonce pour les différents pôle *(avec radius)*
- **Narration [RP]** : Pour faire des annonces [RP] à la totalité des joueurs.
- **Broadcast [HRP]** : Pour faire des annonces [HRP] à la totalité joueurs.
